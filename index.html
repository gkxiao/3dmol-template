使用说明

这是一个完全离线的 3D 结构查看器。把整个文件夹压缩发给同事，对方解压后双击 index.html 即可使用：不需要安装 PyMOL / Schrödinger，不需要联网，也不需要启动服务器。建议用 Chrome / Edge / Firefox 打开。

基本操作

  • 左侧「配体」列表勾选要显示的分子；点击名称可查看该分子的全部 SDF 属性并自动聚焦。
  • 「氢原子显示」默认仅极性氢（与 N / O / S / P 相连的 H，用于观察氢键），可切换为「隐藏」或「全部氢」。规则对配体和蛋白一致：蛋白在线框或口袋残基侧链等原子级表示下，极性氢以与蛋白原子完全相同的 line / stick 样式显示；cartoon 不画单原子时自动隐藏。PDB 没有显式氢则自动跳过。数量见分子详情卡片。
  • 同名分子会被归为一组，组内每个 pose 可单独勾选，方便比较不同 pose。
  • 鼠标左键拖动旋转，滚轮缩放，右键拖动平移；悬停原子显示所属分子 / 残基信息。
  • 「口袋残基」按距离阈值找出与当前可见配体接触的蛋白残基并以棍状显示；可调 3.0–8.0 Å，并可打开残基标签。
  • 「距离测量」开启后依次点击两个原子，显示两点间距离（Å），第三次点击清除。
  • 「导出 PNG」把当前画面存成图片，可直接贴进 PPT / 报告。
  • 快捷键：R 全景、F 聚焦、H 收起面板、/ 搜索、Esc 关闭弹窗。

分享一组特定的分子组合

点击「复制当前选择链接」，把得到的地址发给同事；同事打开自己的 index.html 后，把地址中 # 及其后面的部分粘到自己地址栏末尾并回车，就会显示相同的分子组合。

换成自己的数据

把新的 *.pdb 和 *.sdf（V2000 / V3000 均可）放进本文件夹，在此目录执行：

python build_data.py（也可显式指定：python build_data.py receptor.pdb ligands.sdf）

脚本会重新生成 data.js，刷新页面即可。SDF 里的属性字段、同名 pose 分组都会被自动读取；打分 / 分子量 / 相似度等常见字段会自动识别用于列表摘要与排序（找不到的排序项会自动置灰），其余自定义属性在详情卡中可查；不需要改动 HTML。换项目后建议点一次「重置视图」，或直接用新的文件夹，界面设置不会串台。

3Dmol.js 2.5.5 原生支持 V3000，当前数据集的全部显式氢原子均可直接读入，因此默认使用原始 V3000 文件。若需要给其他软件用，可生成一份保留全氢的 V2000 版：python build_data.py --v2000，输出到 v2000/*_v2000.sdf；想让本查看器改用该文件，执行 python build_data.py <蛋白>.pdb v2000/<文件名> 再刷新即可。

文件清单与许可

index.html（界面）、data.js（内嵌结构数据）、3Dmol-min.js（3Dmol.js 2.5.5，开源 3D 渲染库，本地副本）、build_data.py（数据生成脚本）、v2000/（V2000 兼容副本）、原始 PDB / SDF。3Dmol.js 采用 BSD-3-Clause 许可，全文见 3Dmol-LICENSE.txt。

结构文本之所以内嵌在 data.js 而不是运行时读取，是因为浏览器在 file:// 下禁止 JS 直接读取同目录文件；这是保证「双击即用」的关键。
